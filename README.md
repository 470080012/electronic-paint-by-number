# 电子数字油画

一款数字填色小工具。可以从图库选画，也可以上传照片，生成带编号的色块。作品进度保存在当前设备，可以从画册继续画，完成后可装裱和导出。

仓库源码对应小红书 V1.0.4 送审包。

## 本地试玩

在仓库根目录运行：

```sh
python3 "开发工具/serve.py" --no-open
```

打开终端显示的地址即可进入图库，默认是 `http://127.0.0.1:4198/`。在 macOS 上也可以双击 `启动本地.command`，直接打开制作页。

普通浏览器可试玩图库填色、照片转数字油画、存档与导出。原生关注、赞赏和小红书发笔记入口需要在小红书 App 的小工具容器中体验。

## 打包

```sh
mkdir -p "检查报告"
python3 "开发工具/package.py"
```

ZIP 输出到 `上传包/`。字体、照片和图库素材说明见 [素材说明](源文件/resources/credits.json)。
